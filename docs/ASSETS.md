# 新用户要准备什么（模型与环境推荐）

`cover init` 和 `cover plan` 会按这台机器的实际情况，告诉你「还需要下什么、多大、从哪拿」。

## 判断依据

- 有没有显卡、显存多大
- 磁盘还剩多少
- 要不要自己训练音色
- 本机是不是已经有 RVC / UVR（有就不下）

## 四种典型结果

| 场景 | 组合 | 约占用 | 主要差别 |
|---|---|---|---|
| 已有 RVC + UVR | 复用本机 | 0G | 什么都不用下，`cover link --auto` 认一下就行 |
| 全新 + 8G 显卡 + 只翻唱 | minimal_gpu | 3.6G | torch CUDA 2.6G 是主力，分离用 becruily |
| 全新 + 8G 显卡 + 要训练 | minimal_gpu_train | 3.8G | 多 200MB 预训练底模 |
| 全新 + 4~6G 显卡 | low_vram | 3.3G | 分离换 hp2，显存峰值从 3.5G 降到 1.2G |
| 全新 + 没有显卡 | cpu_only | 1.0G | torch CPU 版，一首十几分钟 |

## 为什么不当场帮你下载

第三方权重的下载地址和授权随时会变（RVC 仓库结构、UVR 模型页、HuggingFace 镜像都可能改），
写死链接半年后必然失效。所以这里只给「文件名 + 大小 + 从哪拿」，
pip 那几行可以直接复制执行，权重去上游页面下载放到对应目录。

`assets/manifest.yaml` 是清单本体，想加自己的模型（比如换了别的分离模型）直接往里加条目。

## 在哪儿看

- 命令行：`cover init`（首次设置）、`cover plan`（选完方案后）
- 界面：方案页「这套方案还要准备什么？」可展开看明细
- 接口：`GET /api/plan` 返回里的 `assets` 字段
