## 二、功能层（用户行为带来的风险）

### 1. 词曲与录音版权
- 翻唱本身属于「改编/表演」，**自娱不构成侵权传播**；一旦上传到公开平台（B站/网易云/抖音）就涉及词曲著作权与录音制作者权。
- 项目做法：成品默认只留在本地 `4-成品`；`send.enabled` **默认 false**，不自动外发。
- 用户须知：公开传播前自行取得授权；不要用于商业用途。

### 2. 声音权与人格权（最重要的风险）
- 用他人声音训练/转换，可能侵害**声音权益**（民法典第1023条参照肖像权保护），也可能违反平台规则。
- 项目做法：不附带任何音色模型；训练页提示「仅使用你拥有授权的声音」。
- 用户须知：**只训练自己的声音**，或取得明确书面同意；公开分享模型前必须获得权利人许可。

### 3. 平台服务条款
- B站 / 网易云 / QQ 音乐 的接口与内容受其服务条款约束；批量抓取、绕过风控、二次分发都可能违约甚至违法。
- 项目做法：只做单曲检索与试听级下载；**不内置任何绕过风控或解密实现**（只留插件接口）。
- 用户须知：仅个人试听；不要批量下载、不要二次分发。

### 4. 角色与商标
- 「洛天依」「初星学園」等名称与形象属于他人知识产权。内部命名自用一般无碍，**公开宣传/商品化会侵权**。
- 项目做法：示例里不出现具体角色名作为产品名；模型命名由用户自定。
- 用户须知：公开材料里用「示例音色 A」这类中性名。

### 5. 隐私与数据
- 界面与日志会暴露本机路径；`/docs` 页面会显示 Agent key。
- 项目做法（已实现）：日志写入前把用户目录替换为 `~`；`/docs` 的 key 默认打码，点「显示」才明文；服务只监听 `127.0.0.1`。
- 用户须知：贴日志求助前，自己再扫一遍有没有路径/账号。

### 6. 二次分发边界
- **代码可以**（MIT）。
- **模型权重、声音样本、歌曲文件不可以**——它们不在本项目的授权范围内，且可能涉及第三方权利。
